# 병렬 캐릭터 LCD (HD44780, 16핀) — A보드 연결표

I2C가 없는 일반 캐릭터 LCD를 4비트 모드로 연결.
라이브러리: **LiquidCrystal** (아두이노 기본 포함, 별도 설치 불필요)

## 연결표

| LCD 핀 | 이름 | → 연결 |
|---|---|---|
| 1 | VSS | GND |
| 2 | VDD | 5V |
| 3 | V0 | 10kΩ 가변저항 가운데(와이퍼) — 글자 진하기 |
| 4 | RS | **IO13** |
| 5 | RW | GND (항상 쓰기만) |
| 6 | E | **IO14** |
| 7~10 | D0~D3 | 미사용 (4비트 모드) |
| 11 | D4 | **IO27** |
| 12 | D5 | **IO16** |
| 13 | D6 | **IO17** |
| 14 | D7 | **IO18** |
| 15 | A (백라이트+) | 5V (220Ω 저항 권장) |
| 16 | K (백라이트−) | GND |

## 가변저항(콘트라스트)
- 10kΩ 가변저항: 양끝 → 5V / GND, 가운데(와이퍼) → LCD 3번(V0)
- 처음 켜고 글자가 안 보이면 이 가변저항을 돌려 진하기 조절

## 주의
- LCD VDD·백라이트는 **5V**, ESP32 신호는 3.3V. HD44780은 보통 3.3V 신호를
  HIGH로 잘 인식해 동작합니다. (혹시 글자가 깨지면 신호용 레벨시프터 추가)
- A보드 센서핀(IO4·33·32·34·35)과 겹치지 않음. VDD·백라이트는 5V 레일에서 공급.
- 코드 상단 LCD_COLS / LCD_ROWS 를 본인 LCD(16x2 또는 20x4)에 맞게 설정.

## 표시 내용 (영문/숫자 — 캐릭터 LCD는 한글 불가)
20x4 예시:
```
Temp:24.8C  pH:7.10
Turb:12   Lux:63%
Water:OK   Heat:ON
Air:ON P1:OFF P2:ON
```
16x2는 2페이지가 번갈아 표시됩니다.

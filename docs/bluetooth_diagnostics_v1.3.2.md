# v1.3.2 BLE 서비스 호환성 및 진단

B보드에는 연결 표시가 나오지만 앱에 `기기에 수조 제어 서비스가 없습니다`가 표시되는 경우, BLE 연결 이후의 서비스/특성 검사에서 실패한 것입니다. 이 메시지만으로 서비스 UUID 불일치, 특성 누락, 알림/쓰기 속성 부족을 구분할 수 없었습니다.

v1.3.2는 다음 처리를 추가합니다.

- 앱과 같은 명령/상태 특성 UUID 쌍이 하나의 서비스에 있으면, 해당 서비스의 UUID가 달라도 사용합니다.
- 호환 특성이 없으면 Android 서비스 캐시 갱신을 요청하고 600ms 후 서비스 검색을 한 번 더 시도합니다. 캐시 갱신을 지원하지 않는 OS에서는 오류를 기록한 뒤 재검색합니다.
- 다른 UUID를 임의로 명령 특성에 연결하지 않고 실제 발견한 서비스 UUID, 특성 UUID, read/write/notify/indicate 속성을 진단에 보존합니다.
- 설정에서 `연결 진단 보기 · 복사`를 눌러 진단을 확인하고 복사할 수 있습니다. 진단은 앱 밖으로 자동 전송하지 않습니다.
- 특성 누락과 쓰기/알림 미지원 오류를 구분합니다.

## 설치 및 현장 확인

버전은 `1.3.2+6`이며 v1.3.1과 같은 서명키를 사용합니다. v1.3.1 사용자는 앱을 삭제하지 않고 설치할 수 있습니다. v1.3.0은 서명키가 달라 삭제 후 설치해야 합니다.

- [APK 다운로드](https://raw.githubusercontent.com/ericalapiestral-hash/A1/main/app/AquaControl-v1.3.2.apk)
- [ZIP 다운로드](https://raw.githubusercontent.com/ericalapiestral-hash/A1/main/app/AquaControl-v1.3.2.zip)

1. 새 APK 설치 후 앱 설정에서 블루투스를 선택하고 `다시 검색`을 누릅니다.
2. 연결이 완료되고 센서값이 들어오는지 확인합니다.
3. 여전히 오류가 나면 `연결 진단 보기 · 복사` → `복사`를 누르고 진단을 공유합니다. 실제 보드의 UUID와 데이터 규격을 확인한 뒤 호환 처리를 정할 수 있습니다.

현재 설치된 보드 펌웨어는 확인되지 않았습니다. 저장소의 `B_board.ino`와 앱의 UUID는 일치하지만, 저장소 B보드 코드는 `AquaControl`이라는 이름을 사용하며 LCD 제어 코드는 없습니다. `Aquarium` 이름과 LCD 연결 표시만으로 저장소 펌웨어가 설치됐다고 단정할 수 없습니다.

## 검증

Flutter 테스트 14개와 변경 파일의 코드 분석이 통과했습니다. 서비스 UUID만 다른 경우, 첫 서비스 목록 누락 후 재검색 성공, 다른 특성 UUID에서 제어 차단 및 진단 보존, 알림 속성 미지원, 재검색 도중 모드 변경 취소를 검증했습니다. 실제 Galaxy A34 / Android 16 / B보드 조합의 연결과 Android의 네이티브 캐시 갱신 결과는 현장 확인이 필요합니다.

# ESP32 B보드 — 제어 연결표 (코드 기준 / 버스 배선)

보드: **ESP32 WROOM-32**
스위칭: **3채널 릴레이 모듈** (LOW 트리거 = 신호 LOW일 때 ON)
배선 원칙(안정성): 릴레이 VCC/GND·ESP32를 **공통 GND 버스**로 1점 접지 +
릴레이 모듈 VCC↔GND에 **10uF/0.1uF 디커플링**으로 코일 스파이크 흡수.

> ⚠️ 이전 control_table(SSR + 산소릴레이, IO33/IO32/IO26 버전)은 **폐기**.
> 현재 코드([B_board.ino](../B_board/B_board.ino))·README·테스트가 일치하는 아래 구성이 정답입니다.

## 구성 (확정)

- HE-50W 히터: **220V AC** (돼지코) — 릴레이 CH3
- 펌프1(급수): SZH-PWAT-040 **12V DC** — 릴레이 CH1 (수위 기반)
- 펌프2(순환): **협신 UP200 (단상 220V AC · 20W)** — 릴레이 CH2 (타이머)
  - 전원코드 활선(L)을 잘라 릴레이 접점에 **직렬** 삽입. 상세: [UP200_circulation_wiring.svg](UP200_circulation_wiring.svg) / 코드 [UP200_pump.ino](../UP200_pump/UP200_pump.ino)
- 산소(oxygen): **핀 없는 로직 전용** (앱 상태/타이머만, 물리 출력 없음)

## 제어선 (저전압, ESP32 ↔ 릴레이 모듈)

| ESP32 핀 | → 연결 | 비고 |
|---|---|---|
| 5V | 릴레이 모듈 **VCC** | (+ VCC–GND 10uF/0.1uF 디커플링) |
| GND | 릴레이 모듈 **GND** | 공통 GND 버스 |
| **IO25** | 릴레이 **IN1** | 펌프1(급수), **LOW=ON** |
| **IO26** | 릴레이 **IN2** | 펌프2(순환), **LOW=ON** |
| **IO27** | 릴레이 **IN3** | 히터, **LOW=ON** |

> 릴레이가 반대로 동작하면 코드의 `RELAY_LOW_TRIG = false` 로 토글.
> GND는 ESP32·릴레이 모듈이 반드시 공통이어야 합니다.

## 전력선 (고전압/부하 측)

### 히터 (220V, 릴레이 CH3)
| 출발 | → 도착 |
|---|---|
| 220V 콘센트 **L** | 릴레이 CH3 **COM** |
| 릴레이 CH3 **NO** | 히터 **L** |
| 220V 콘센트 **N** | 히터 **N** |

### 펌프1 - 급수 (12V DC, 릴레이 CH1)
| 출발 | → 도착 |
|---|---|
| 12V 어댑터 **+** | 릴레이 CH1 **COM** |
| 릴레이 CH1 **NO** | 펌프1 **+** |
| 12V 어댑터 **-** | 펌프1 **-** |

### 펌프2 - 순환 (협신 UP200, 220V AC, 릴레이 CH2)
| 출발 | → 도착 |
|---|---|
| 220V 콘센트 **L** (활선, 코드 절단) | 릴레이 CH2 **COM** |
| 릴레이 CH2 **NO** | UP200 **L** |
| 220V 콘센트 **N** (안 자름) | UP200 **N** |

> 펌프2는 12V DC가 아니라 **220V AC 수중모터(UP200)**. 히터처럼 **활선 L 만 잘라 릴레이에 직렬**로 넣음(N은 직결).
> 릴레이 접점 250VAC 이상 정격 확인. OFF여도 N은 통전되므로 손댈 땐 콘센트째 분리. (급수 펌프1만 12V 어댑터 사용)

## 전원 / 안전

- ESP32: **USB 어댑터(5V)** 상시 급전. (릴레이 코일 여유 위해 1.5~2A 권장)
- **220V 배선은 반드시 전원(돼지코) 뽑은 상태에서** 작업. L/N 단자 절연, 노출 금지.
- 12V(급수펌프)와 220V(순환펌프 UP200·히터) 배선은 **물리적으로 분리**.
- 릴레이는 부하 정격의 2~3배 여유 제품 사용.
- 코드 시작 시 전 채널 OFF, A보드 신호 15초 끊기면 히터 자동 OFF.
- 릴레이 모듈 VCC에 **디커플링 커패시터(10uF/0.1uF)** 를 붙이면 코일 ON/OFF 시 리셋·오작동이 크게 줄어듭니다.

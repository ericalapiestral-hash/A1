# A보드 센서 연결표 — 수온 제거 구성

현재 센서는 조도·탁도·pH·수위 4종입니다. DS18B20, GPIO4 데이터선, 4.7kΩ 풀업, OneWire/DallasTemperature 의존성은 기본 A보드 코드에서 제거했습니다. 센서 DATA뿐 아니라 해당 센서 전원·GND도 분리할 때 다른 센서의 공통 레일을 끊지 않도록 확인합니다.

| 센서 | 신호 GPIO | 전원 | 신호 회로(문서 기준) |
|---|---|---|---|
| GL5528 상대 조도 | IO33 | 3.3V | 3.3V–LDR–노드–10kΩ–GND, 노드–GND 0.1µF |
| SEN0189 탁도 | IO32 | 5V | OUT–10kΩ–노드–20kΩ–GND, 노드–GND 0.1µF |
| PH4502C pH | IO34 | 5V | PO–10kΩ–노드–20kΩ–GND, 노드–GND 1µF |
| XKC-Y25-V 수위 | IO35 | 5V | OUT–10kΩ–노드–20kΩ–GND, digitalRead |

GND는 A보드 내부 센서·LCD·분압·필터와 공통입니다. IO34·35는 입력 전용이며 조도는 lux가 아닌 상대 %입니다. 문서의 10kΩ/20kΩ 분압은 5V 입력에서 이론상 3.33V이므로 최대 출력·저항 오차·ESP32 입력 정격을 확인해야 합니다.

LCD는 RS=13, E=14, D4=27, D5=16, D6=17, D7=18입니다. pH·탁도·조도·수위 4페이지를 2초마다 표시합니다.

A→B 센서 패킷은 16바이트입니다. 새 B보드는 기존 20바이트도 받아 수온을 무시합니다. 저장소 코드 적용 시 B 먼저 갱신합니다. 실제 Aquarium의 핀·펌웨어는 미확인이며 기존 배선 이미지는 수온을 포함한 과거 구성입니다.

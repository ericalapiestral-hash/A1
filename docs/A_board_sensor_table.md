# ESP32 A보드 — 센서 연결표 (브레드보드 + 확장보드, 버스/필터 배선)

보드: **ESP32 38핀 DevKit + GPIO 확장보드(S/V/G 헤더)** + 브레드보드
원칙:
- 아날로그 센서는 **ADC1(IO32~39)** 에만 → ESP-NOW(WiFi 라디오)와 충돌 없음.
- 전원/GND는 **레일(버스)로 한 줄씩 정리**(데이지체인). 한 핀에 여러 가닥 꽂는 병렬 난잡 배선 금지.
- 아날로그 출력 노드마다 **필터 커패시터**(0.1uF~1uF)로 ADC 노이즈 제거.
- **GND는 전부 한 점 공통** (센서·분압저항·커패시터·ESP32·확장보드).

## 전원 레일 2개

| 레일 | 공급원 | 사용 센서 | 이유 |
|---|---|---|---|
| **5V 레일** | 확장보드 V(5V 점퍼) 또는 ESP32 VIN/5V | 탁도 · pH · 수위 · LCD | 5V 동작 센서 |
| **3.3V 레일** | ESP32 **3V3** 핀 | 수온(DS18B20) · 조도(GL5528) | 신호가 native 3.3V → 분압/레벨변환 불필요 = 더 안정 |
| **GND 레일** | 공통 1점 | 전부 | — |

> 확장보드 V 점퍼가 **3.3V/5V 한 가지로 통째 선택**되는 모델이면: V 레일=**5V**로 두고,
> 3.3V가 필요한 수온·조도는 ESP32 **3V3 핀**에서 별도 미니레일을 따서 쓰세요.

## 전원 레일 커패시터 (버스 안정화)

| 위치 | 커패시터 | 역할 |
|---|---|---|
| 5V 레일 ↔ GND | **10uF + 0.1uF** | 5V 센서 전원 노이즈/순간강하 흡수 |
| 3.3V 레일 ↔ GND | **10uF + 0.1uF** | 수온/조도 전원 안정화 |

## 전원

- **USB 어댑터(5V, 1A 이상)** 를 ESP32 USB-C 포트에 연결 → 상시 급전.
- 5V 센서는 5V 레일, 3.3V 센서는 3V3 레일에서 공급.
- 수조 근처라 어댑터·케이블은 물 안 닿는 곳에.

## 꼭 지킬 점

- **5V 센서(탁도·pH·수위)는 반드시 분압 저항을 거쳐서** ESP32에 입력. 직접 연결 시 3.3V 초과로 핀 손상.
  - 10kΩ 직렬 + 20kΩ→GND => 약 ×0.67 로 안전 (코드에서 ×1.5로 복원).
- **수온·조도는 3.3V 레일에서 구동** → 출력이 native 3.3V라 분압 없이 바로 ADC 입력 가능(레벨변환 불필요).
- **GND는 모두 한 점 공통**으로 묶기 (센서·ESP32·분압·커패시터 동일 GND).
- 아날로그 노드 커패시터는 **분압저항과 ADC 핀 사이 노드 ↔ GND**에 붙임 (RC 저역통과).
- 브레드보드에서 먼저 값 확인 → 안정되면 그대로 사용.
- DS18B20이 -127℃로 나오면 4.7kΩ 풀업/3.3V 배선 확인.

> 이전 문서(v1)의 조도 IO36 / 탁도 IO39 는 **폐기**. 현재 코드·배선은 **조도 IO33 / 탁도 IO32** 입니다.

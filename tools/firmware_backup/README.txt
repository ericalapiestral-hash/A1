AquaControl B보드 펌웨어 백업 v1.0

원래 Aquarium 소스가 없어 현재 보드의 전체 플래시를 BIN으로 보존하고 명령 처리 분석 자료를 확보하는 도구입니다.
ZIP을 풀고 HTML을 Windows Edge/Chrome에서 엽니다. EXE·CMD·PS1 실행, Arduino IDE·Python 설치가 필요하지 않습니다.

중요: 단순 로그 읽기와 달리 보드를 부트로더로 재부팅하고 임시 읽기 코드를 RAM에서 실행합니다. 플래시에는 쓰거나 삭제하지 않습니다.
백업 중 수조 제어는 중단됩니다. 순환펌프·히터 전원을 끄고 기존 PC 로그 프로그램의 시리얼 연결을 종료합니다.
확인 항목을 체크한 뒤 B보드 선택·전체 백업에서 현재 B의 COM5를 선택합니다.
현재 일반 ESP32만 지원하며 플래시 용량은 자동 감지합니다. 다른 칩·보안 다운로드 모드·미확인 용량은 거부합니다.
115200 baud로 몇 분 소요될 수 있습니다. 보드 MD5와 BIN MD5를 비교한 뒤 일치한 경우에만 BIN 저장을 제공합니다.
완료 후 BIN과 보고서 TXT를 각각 저장해 채팅에 첨부합니다. 보드 설정도 포함될 수 있어 공개 저장소에 올리지 않습니다.
성공 시 기존 펌웨어 재시작을 요청합니다. 실패·중단 뒤에는 부하 전원을 끈 상태에서 USB를 다시 연결합니다.
자동 연결에 실패하면 BOOT를 누른 상태에서 EN/RESET을 한 번 누르는 보드의 부트로더 진입 방법을 확인합니다.
기존 펌웨어 업로드·삭제는 필요하지 않습니다. BIN은 원본 Arduino 소스가 아니며 분석으로 모든 코드가 복원되지는 않습니다.

보안 설정 변경을 요구하지 않습니다. 조직의 브라우저·USB 제한이나 모든 Windows 보안 제품에서의 동작을 보장하지는 않습니다.
로그와 BIN은 브라우저에서 처리하며 서버로 자동 전송하지 않습니다.
Espressif esptool-js 0.7.0(Apache-2.0), SparkMD5 3.0.2(MIT)의 공식 npm 배포를 고정해 포함합니다. 출처·체크섬·라이선스는 licenses 폴더를 참고합니다.
공식 API: https://github.com/espressif/esptool-js

검증: 모의 ESP32 로더의 명령 제한, 전체 크기, MD5 일치/불일치, 오류 처리와 브라우저 다운로드를 검증합니다.
실제 Windows/ESP32 백업은 이 작업 환경에서 수행하지 않았습니다. 실패 시 보고서 TXT로 원인을 확인합니다.

Aquarium B 히터 수동 제어 업데이트 v1.2.0

기존 앱 v1.3.8의 히터 끄기·켜기를 지원합니다. 급수 수동·순환 수동/자동·센서·LCD는 유지합니다. 수온 측정·온도 자동 제어는 없습니다.

1. 배선이 미확인이면 먼저 잠금 상태로 설치

현재 Aquarium 히터 핀은 GPIO18입니다. 저장소의 예전 GPIO27 설계와 다릅니다. 코드로 실제 선 연결이나 히터 온도·전류를 확인할 수는 없습니다.

  1. 히터·급수·순환 등 모든 부하의 전원 플러그를 뽑고 B만 USB로 연결합니다. 기존 로그/백업/점검 프로그램의 시리얼 연결을 종료합니다.
  2. 배선을 모르면 히터 설정을 기본 잠금 유지로 둡니다. 원본 4MB B BIN을 선택하고 B COM5로 설치합니다.
  3. 완료 후 이 화면의 연결이 닫히면 ZIP의 Heater-Relay-Check.html을 열어 B COM5를 연결합니다. 모든 부하 전원을 뽑은 상태에서 GPIO18 LOW/HIGH 반응을 점검합니다.
  4. 어느 릴레이가 반응하는지, 그 릴레이가 실제 히터에 연결됐는지와 정지 신호를 확인합니다. LED/딸깍 소리만으로 NO/NC나 히터 정지를 단정하지 마세요.
  5. 배선과 정지 신호를 확인한 뒤 점검 도구 연결을 종료하고 이 도구에서 히터 신호를 선택해 다시 설치합니다. 모르면 잠금을 유지하고 점검 보고서를 전달하세요.

점검은 실제 히터 가열 시험이 아닙니다. 220V 접점은 전원을 분리한 상태에서 적절한 작업자가 확인해야 합니다. 히터 자체 온도조절·과열보호가 있는지 제품 사양도 확인합니다.

2. 설정과 설치

원본·v1.0.1·v1.1.0·v1.2.0의 일치하는 이미지를 확인한 후 B 앱 영역만 씁니다. A·부트로더·파티션·NVS·SPIFFS를 덮어쓰지 않습니다. 잠금 설치는 GPIO18의 기존 HIGH를 유지하며 실제 히터 OFF를 보장하는 설정은 아닙니다. 부하 전원 분리를 유지하세요.

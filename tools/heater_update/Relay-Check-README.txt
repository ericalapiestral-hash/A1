GPIO18 릴레이 점검 도구 v1.2.1 — B 펌웨어 v1.2.0용

이 ZIP의 HTML은 PC의 점검 화면입니다. 펌웨어를 기록하거나 지우지 않습니다.
B에 v1.2.0을 설치했다면 BIN이나 업데이트 작업을 다시 할 필요가 없습니다.

1. 히터·급수·순환 등 모든 부하 전원 플러그를 뽑고 B와 제어측만 USB 전원을 연결합니다.
   USB 연결/리셋 신호 변경으로 B가 재시작될 수 있으므로 부하 전원 분리를 유지합니다.
2. 기존 점검/업데이트/Arduino 시리얼 도구의 연결 종료를 누르고 이전 점검 창을 닫습니다.
3. ZIP을 풀어 새 Heater-Relay-Check.html을 Windows Edge/Chrome에서 엽니다.
   화면 제목에 v1.2.1이 있는지 확인합니다.
4. B보드의 COM 포트를 선택합니다. 기존에는 COM5였지만 목록에서 현재 B를 선택합니다.
5. 도구가 DTR/RTS를 해제하고 읽기 전용 status 명령을 요청합니다.
   수신 바이트 수와 펌웨어/잠금 상태가 표시되는지 확인합니다.
6. 8초가 지나도 수신 0바이트이면 부하 전원 분리 확인을 체크하고
   [B 정상 재시작 · 펌웨어 유지]를 한 번 누릅니다.
   지원되지 않으면 보드의 EN/RST 버튼을 한 번 누릅니다. BOOT는 누르지 않습니다.
7. B v1.2.0 잠금 상태가 확인되면 전원 분리 확인 후 LOW/HIGH 점검 버튼이 활성화됩니다.
   원래대로 GPIO18만 최대5초 바꾸고 기존 HIGH로 돌아갑니다. 실제 히터 OFF 보장은 아닙니다.
8. 여전히 안 되면 화면 아래 로그와 수신 바이트 수가 들어간 점검 보고서 TXT를 저장해 전달합니다.

상태별 의미
  수신0바이트: 리셋/실행 상태, 잘못 선택한 COM, USB/UART 경로 등을 확인해야 합니다.
  DOWNLOAD_BOOT 또는 waiting for download: 프로그램 실행이 아닌 다운로드 대기입니다.
    부하 전원 분리 후 정상 재시작 또는 EN/RST를 사용하고 BOOT를 누르지 않습니다.
  이전 펌웨어/다른 JSON: B에 히터 잠금 v1.2.0을 설치했는지 또는 B의 COM인지 확인합니다.
  히터 활성화 상태: 잠금 점검용 명령이 차단됩니다. 점검하려면 잠금 설정으로 설치해야 합니다.
  상태가 오래됨/USB 수신 종료: LOW/HIGH를 차단합니다. 연결을 종료하고 다시 연결합니다.

바뀐 내용
  - 연결 직후 기존 로그 도구와 같은 DTR/RTS 해제
  - 연결 후 자동 status 요청 3회, 수동 상태 다시 요청
  - 수신 바이트/상태 수/신호 해제 결과 표시와 무수신 안내
  - 사용자 요청으로만 정상 부팅 리셋(BOOT 해제 상태, 플래시 쓰기 없음)
  - 로그 접두사·나뉜 JSON·줄바꿈 없는 완성 상태와 최초 불완전 프레임 처리
  - 펌웨어/잠금/부하 전원 확인/최근 상태 조건은 유지

실물 USB 보드에서 이 수정의 효과는 아직 확인하지 않았습니다.
실제 히터 연결·전류·온도·릴레이 접점은 자동 판정하지 않습니다.
파일과 로그는 브라우저 안에서만 처리하고 서버로 자동 전송하지 않습니다.

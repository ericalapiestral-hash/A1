Aquarium B 순환 제어 업데이트 v1.0

이 도구는 제공된 4MB Aquarium B 백업을 분석해 만든 순환 전용 새 프로그램을 적용합니다.
원본 소스가 복원된 것은 아닙니다. 기존 코드의 GPIO17, LCD 13/14/27/26/25/33, 12바이트 A 센서 수신·송신 보드 필터·BLE UUID를 유지합니다.
수동 OFF/ON/AUTO와 앱의 pump2Mode/circOn/circOff를 처리하고 적용 모드를 상태로 돌려줍니다. 수동 OFF는 타이머·센서 단절·BLE 단절에도 유지됩니다. 전원 재시작 기본 OFF입니다.
현재 관찰에 맞춰 GPIO17 LOW=순환 정지, HIGH=작동입니다. 실제 반대 동작의 원인이 릴레이 트리거인지 NC 접점인지까지 확정한 것은 아닙니다.
릴레이·보드 전원이 꺼졌을 때에도 펌프가 정지한다고 보장하지 않습니다. 전원 단절 시 정지가 필요하면 전원을 완전히 끈 상태에서 NO/NC 접점·트리거 배선을 확인해야 합니다.

1. 순환펌프·히터 전원을 끄고 B보드를 PC USB에 연결합니다. 급수·히터는 이 프로그램에서 제어하지 않으므로 해당 장치 전원은 분리 상태를 유지합니다.
2. 기존 PC 점검/백업 프로그램에서 연결 종료를 누릅니다.
3. ZIP을 풀어 HTML을 최신 Edge/Chrome에서 엽니다. EXE/CMD/PS1·Arduino IDE 설치가 필요하지 않습니다.
4. 기존 B보드의 4MB BIN 백업을 선택합니다. 이번에 분석한 파일과 SHA-256이 같아야 진행됩니다.
5. 기본 작업 [순환 수동 제어 업데이트], 준비 확인을 선택한 뒤 [B보드 선택·작업 시작]에서 현재 COM5를 선택합니다.
6. 현재 펌웨어·파티션·칩을 확인한 뒤 앱 영역 0x10000만 씁니다. 부트로더·NVS 설정·SPIFFS·A보드에는 쓰지 않습니다.
7. 체크섬 검증 완료 후 앱 v1.3.7을 Aquarium에 다시 연결합니다. 순환 OFF 상태를 확인하고 켜기·끄기를 각각 확인합니다. AUTO는 작동 2분/휴식 1분을 기본으로 시작합니다.
8. 오류가 나면 보고서 TXT를 저장합니다. 쓰기 시작 이후 실패는 같은 화면에서 [원본 B 프로그램 복원]을 선택해 다시 진행할 수 있습니다. 대상 기록을 브라우저가 저장할 수 없으면 화면을 닫기 전에 복원을 진행합니다.

원본 복원도 앱 영역만 되돌립니다. 복원 후에는 기존 명령 미지원·반대 출력 동작이 돌아옵니다.
장치 식별 해시는 대상 확인·실패 복원을 위해 브라우저에만 저장합니다. 서버로 파일·로그를 전송하지 않습니다.
보안 부팅·플래시 암호화 설정, 다른 칩/용량/파티션/펌웨어는 거부합니다. 전체 플래시 삭제 기능은 제공하지 않습니다.
백업에서 원래 A 송신 필터 6바이트만 브라우저 안에서 새 프로그램에 복사합니다. 공개 소스·배포 템플릿에 사용자의 MAC이나 기존 백업은 포함하지 않습니다.
급수·히터 핀 GPIO16/18은 원래 B의 부팅 HIGH로 유지하지만 실제 장치 OFF 여부를 검증한 것은 아닙니다. 해당 부하를 다시 사용하려면 별도 배선·극성·제어 검증이 필요합니다.

Arduino CLI 컴파일·순환 상태/파싱/센서 패킷 테스트와 모의 브라우저 업데이터로 검증합니다. 실제 Windows/ESP32 업로드·펌프 작동은 현장 확인 단계입니다.
Espressif esptool-js 0.7.0·SparkMD5 3.0.2, ZIP 내 라이선스 참조.

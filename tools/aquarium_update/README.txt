Aquarium B 급수 수동 제어 업데이트 v1.1.0

급수는 수동 끄기/켜기만 지원합니다. 수위와 타이머로 자동 급수하지 않습니다.
순환은 기존 끄기/켜기/자동과 시간 설정을 그대로 지원합니다. A 센서 통신·LCD·BLE UUID를 유지합니다.
B보드 GPIO16=급수, GPIO17=순환, GPIO18=히터 미사용입니다. 히터 전원은 분리 상태를 유지합니다.

설치 전 급수 설정 확인:
현재 잘 작동하는 순환 v1.0.1에서는 급수 GPIO16이 HIGH로 유지됩니다.
급수 펌프 전원을 연결했을 때 앱 조작 없이 정지하는지 작동하는지 잠깐 확인하세요.
물이 나올 수 있으므로 확인하는 동안 지켜보고 확인 후 급수 전원을 다시 끄세요.
HTML에서 확인한 상태를 선택합니다. 모르면 임의로 선택해 설치하지 말고 현재 상태를 알려주세요.
이 선택을 통해 켜기/끄기 출력 신호를 맞춥니다. 선택 전에는 업데이트를 진행하지 않습니다.

1. 급수·순환 펌프와 히터 전원을 끄고, 기존 PC 점검/백업 도구에서 시리얼 연결을 종료합니다.
2. B보드를 PC USB에 연결하고 ZIP의 Aquarium-B-Pump-Update.html을 최신 Edge/Chrome에서 엽니다.
3. 급수 펌프의 기존 상태를 선택하고, 앞서 저장한 원본 4MB B BIN을 선택합니다.
   현재 순환 v1.0.1을 다시 백업하거나 A보드를 업로드할 필요는 없습니다.
4. 기본 급수 수동 제어 업데이트와 준비 확인 후 B의 COM5를 선택합니다.
5. 원본 또는 순환 v1.0.1 또는 새 수동 급수 펌웨어와 파티션/칩이 맞는지 확인한 뒤 앱 영역만 쓰고 MD5를 확인합니다.
6. 휴대폰에 AquaControl v1.3.8 APK를 기존 앱 위에 설치하고 Aquarium을 다시 연결합니다.
7. 새 프로그램의 급수·순환은 부팅 기본 끄기입니다. 펌프 전원을 다시 연결하고 급수 끄기·켜기를 각각 확인합니다.
8. 급수 자동은 없으며 켜기는 사용자가 끌 때까지 유지됩니다. BLE/센서 단절 또는 수위 변화로 자동 정지하지 않습니다.
   B 재부팅 시 급수 OFF로 시작합니다. 비상정지 E1은 두 펌프를 억제하지만 E0 해제 시 유지된 ON 요청이 재적용됩니다.

설치 오류 또는 원래 순환만 쓰려면 같은 화면에서 [잘 작동했던 순환 v1.0.1로 복원]을 선택할 수 있습니다.
더 이전 Aquarium 원본 앱 프로그램 복원도 제공하지만 원래의 수동 제어 미지원 문제가 돌아옵니다.
두 복원 작업 모두 앱 영역만 바꿉니다. 사용하지 않는 급수·히터의 전원은 복원 전에 분리하세요.
잘못 선택한 급수 상태는 올바른 상태를 선택해 같은 B에 다시 설치해 수정할 수 있습니다.
쓰기 실패 후에는 브라우저에 저장한 대상 기록으로 같은 B만 복원할 수 있습니다. 저장 제한 시 화면을 닫지 마세요.

부트로더·파티션·NVS·SPIFFS를 보존합니다. 전체 삭제, 다른 영역 쓰기, 다른 칩/파티션/펌웨어, 보안 부팅/암호화는 거부합니다.
원본 백업과 A 송신 MAC은 공개 소스·템플릿에 포함하지 않습니다. 브라우저 안에서 필터와 급수 설정을 적용합니다.
파일·로그는 서버로 전송하지 않습니다. 대상 식별 해시는 실패 복원을 위해 이 브라우저에만 저장합니다.
보드/릴레이 전원 단절 때에도 실제 펌프가 정지하는지는 NO/NC 접점과 배선에 따라 다르므로 별도 확인이 필요합니다.

컴파일·급수/순환 상태 테스트·업데이트 코어·브라우저 모의 설치/복원 검증을 수행합니다.
실제 급수 GPIO16 배선과 신호 극성·급수펌프 작동은 현장 확인 단계입니다. 순환 v1.0.1은 사용자 실기 확인을 받았습니다.

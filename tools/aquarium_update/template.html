Aquarium B 순환 제어 업데이트 v1.0

현재 백업에서 확인한 GPIO17·LCD·A 센서 통신을 사용하는 순환 전용 B 프로그램입니다. 앱 v1.3.7의 끄기·켜기·자동과 주기 설정을 처리합니다.

1. 준비와 파일 확인

  1. 순환펌프와 히터 전원을 끄고 B보드를 PC USB에 연결합니다. 급수·히터 출력은 이 복구 프로그램에서 제어하지 않습니다.
  2. 기존 로그·백업 프로그램에서 연결 종료를 누릅니다.
  3. 앞서 저장한 4MB B보드 원본 BIN을 선택합니다. 분석한 파일과 맞아야 진행할 수 있습니다.
  4. 아래 준비 확인 후 B보드 선택·작업 시작에서 현재 COM5를 선택합니다.

A보드에는 업로드하지 않습니다. 원본 펌웨어·파티션 확인 후 B의 앱 영역만 씁니다. 부트로더·보드 설정·파일 시스템은 보존합니다. 작업 중 USB를 유지하고 이 화면을 열어두세요.

새 프로그램은 부팅 시 순환 끄기로 시작합니다. 현재 관찰된 배선에 맞춰 GPIO17 LOW=정지, HIGH=작동으로 설정합니다. 앱을 다시 연결해 실제 펌프 정지·회전을 확인하세요. 급수·히터 전원은 분리 상태를 유지합니다. 실기 적용·출력 검증은 현장 확인 단계입니다.

Espressif esptool-js 0.7.0 · SparkMD5 3.0.2 · ZIP 내 라이선스 참조. 파일·로그는 브라우저 안에서 처리하며 서버로 전송하지 않습니다. 대상 식별 해시를 이 브라우저에 저장해 같은 B보드의 실패 복원을 지원합니다.

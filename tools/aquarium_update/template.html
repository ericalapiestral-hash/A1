Aquarium B 급수 수동 제어 업데이트 v1.1.0

급수는 수동 끄기·켜기만 사용합니다. 수위·타이머로 자동 급수하지 않습니다. 순환의 끄기·켜기·자동과 센서·LCD를 유지합니다. 앱 v1.3.8을 함께 설치하세요.

1. 준비와 파일 확인

  1. 현재 순환 v1.0.1에서 급수펌프 전원을 연결했을 때 앱 조작 없이 정지하는지 또는 작동하는지를 먼저 확인합니다. 확인 중 물이 나올 수 있으므로 지켜보며 잠깐 확인하고 급수 전원을 다시 끄세요. 결과를 아래에서 선택합니다. 모르면 업데이트하지 말고 현재 상태를 알려주세요.
  2. 급수·순환펌프와 히터 전원을 끄고 B보드를 PC USB에 연결합니다. 히터는 계속 전원을 분리합니다.
  3. 기존 로그·백업 프로그램에서 연결 종료를 누릅니다.
  4. 앞서 저장한 4MB B보드 원본 BIN을 선택합니다. 분석한 파일과 맞아야 진행할 수 있습니다.
  5. 아래 준비 확인 후 B보드 선택·작업 시작에서 현재 COM5를 선택합니다.

A보드에는 업로드하지 않습니다. 원본 펌웨어·파티션 확인 후 B의 앱 영역만 씁니다. 부트로더·보드 설정·파일 시스템은 보존합니다. 작업 중 USB를 유지하고 이 화면을 열어두세요.

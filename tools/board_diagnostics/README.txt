B보드 USB 로그 수집 (Windows)

Smart App Control이 다운로드 도구를 차단하면 Arduino IDE의 시리얼 모니터를
사용하세요. 보안 설정을 변경할 필요는 없습니다.

Arduino IDE로 확인하기:
1. Arduino IDE가 없으면 공식 https://www.arduino.cc/en/software 에서 설치합니다.
2. B보드를 연결하고 도구 → 포트에서 해당 COM 번호를 선택합니다.
3. 도구 → 시리얼 모니터를 열고 통신 속도를 115200 baud로 설정합니다.
4. 앱의 블루투스를 연결한 상태에서 출력되는 마지막 20~30줄과 COM 번호를 공유합니다.
5. 원래 펌웨어 소스가 없으므로 업로드 버튼은 누르지 마세요.
   로그가 없으면 "출력 없음", 글자가 깨지면 "글자 깨짐"이라고 알려주세요.

아래 다운로드 도구는 실행이 허용되는 PC에서만 사용합니다:
1. ZIP을 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. B보드를 USB 데이터 케이블로 연결합니다.
3. Arduino 시리얼 모니터 등 같은 포트를 사용하는 프로그램을 닫습니다.
4. Run-B-board-capture.cmd를 더블클릭합니다.
5. 목록에서 B보드에 해당하는 COM 번호를 입력합니다. 예: COM5
6. 45초 동안 보드가 출력하는 로그를 읽습니다.
7. diagnostics 폴더의 .log 파일을 열어 내용을 확인하고 공유합니다.

Silicon Labs CP210x 또는 USB-SERIAL CH340 등으로 표시되는 경우가 많습니다.
어느 포트인지 모르면 Windows 장치 관리자 → 포트(COM 및 LPT)에서 확인합니다.

이 도구는 시리얼 출력 읽기와 로컬 로그 저장만 수행합니다. 명령 전송이나
펌웨어 업로드/삭제를 수행하지 않으며 로그를 자동 전송하지 않습니다.
DTR/RTS는 비활성 상태로 설정합니다. 관리자 권한이나 별도 Python 설치는 필요 없습니다.
실행 정책 Bypass는 해당 PowerShell 프로세스에만 적용되고 PC 설정을 변경하지 않습니다.

출력이 없어도 보드 고장으로 단정할 수 없습니다. 실행 중인 펌웨어가 로그를
출력하지 않거나, COM 번호/통신 속도가 다를 수 있습니다. 기본 속도는 115200입니다.
화면의 오류 또는 "No serial output" 메시지도 진단에 도움이 됩니다.

AquaControl 보드 점검

Arduino IDE 없이 USB 로그를 읽고 센서·제어 보고 상태를 확인합니다.

점검 프로그램 v1.1

1. 보드를 연결하세요

Windows PC의 Edge·Chrome에서 USB 데이터 케이블로 연결한 보드를 선택하세요.

브라우저 지원 확인 중…

시리얼 장치: 선택 전

별도 선택 USB 장치: 선택 전

포트 선택창에서 B보드를 선택한 뒤 휴대폰 앱을 BLE로 연결해 주세요.
포트가 안 보이거나 로그가 없을 때
  1. 허용한 포트가 0개라는 표시는 이 화면에 아직 허용하지 않았다는 뜻일 수 있습니다. 먼저 “포트 선택·연결”의 목록을 확인하세요.
  2. 선택 목록이 비면 다른 데이터 USB 케이블·PC USB 포트로 확인하세요. 전원 LED만 켜지는 것은 데이터 연결 확인이 아닙니다.
  3. Windows 장치 관리자에서 보드를 뽑았다 꽂을 때 나타나는 장치를 찾고 하드웨어 ID·오류를 확인하세요. 이 프로그램이 USB 드라이버를 설치해 주지는 않습니다.
  4. 포트는 열리지만 로그가 없으면 펌웨어가 출력하지 않거나 속도가 다를 수 있습니다. 글자가 깨지면 속도를 바꿔 다시 연결하세요.
  5. 읽기만 수행하지만 일부 보드는 포트를 열 때 재부팅됩니다. 현재 펌웨어에 부팅 출력 테스트가 있는 경우 처음 점검은 부하 전원을 분리한 상태에서 하세요.
